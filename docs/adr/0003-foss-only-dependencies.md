# FOSS-only dependencies and assets

Every runtime dependency and bundled asset (libraries, fonts, icons, marks) must be free/open source under a permissive license (MIT, Apache-2.0, ISC, OFL, …), and the licenses must be honored — including visible attribution (e.g. an about/licenses dialog). The motivation is frictionless redistribution: anyone may copy, host, and ship the tool without licensing surprises. Rejected: proprietary or non-commercial-licensed libraries and assets, regardless of convenience.
