# Local-first ohne Backend

mdcovergen runs purely client-side; all data (designs, settings, imported images) lives in the browser or in files owned by the user. Even if it is publicly hosted, hosting is only static file serving — no users, no accounts, no server-side storage. The old tools this replaces are paid web services, and operating a backend would mean ongoing cost, a login barrier, and giving up data sovereignty. Rejected alternatives: a backend with accounts (operating cost, barrier for "non-technical" users) and saving to a server instead of the browser/files.
